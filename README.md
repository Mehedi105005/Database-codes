# CSE 2301 – Blood Bank Management System

**Course:** Database Management System (CSE 2301)  
**Section:** 05  
**University:** University of Liberal Arts Bangladesh  
**Semester:** Spring 2026

This repository contains the MySQL implementation of the Blood Bank Management System described in the submitted project report.

## Contents
- Donor management
- Donation history
- Blood-unit inventory
- Laboratory testing
- Hospital management
- Blood requests and request items
- Blood issue/distribution
- User accounts and roles
- Primary/foreign keys
- Composite keys
- Constraints
- Triggers and views
- SQL demonstration queries

## Run with XAMPP/phpMyAdmin
1. Start MySQL in XAMPP.
2. Open `http://localhost/phpmyadmin`.
3. Go to the SQL tab.
4. Run `01_schema.sql`.
5. Run `02_sample_data.sql`.
6. Run the required queries from `03_queries.sql`.

## Run with MySQL Workbench
Run the three SQL files in this order:
1. `01_schema.sql`
2. `02_sample_data.sql`
3. `03_queries.sql`

The sample credentials are for academic demonstration only.
